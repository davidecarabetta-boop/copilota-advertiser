# Copilota Advertiser

Tool interno SearchOn: dice agli advertiser cosa fare su Google Ads e Meta Ads, account per account, con regole che bloccano le azioni pericolose.

- Contesto e regole di lavoro: `CLAUDE.md`
- Fasi di sviluppo: `fasi/` (stato in `fasi/STATO.md`)
- Regole di modifica e soglie: `config/`
- Mockup: `docs/mockup.html`

Per iniziare con Claude Code: aprire questa cartella e chiedere "partiamo dalla fase 00". Ordine: 00 → 00b (prototipo in chat) in parallelo alla 01 → 02 … 08; la 09 in parallelo alla 06.
